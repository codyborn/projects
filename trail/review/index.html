One per WORK WEEK tap, Professor Layton style, Uniswap engineering. The ✓ marks the answer; players never see it. Solved clean: +$100 a day for the week; with the hint: +$25; wrong twice: -$75. Text lives in src/data/puzzles.json and the Obsidian copy note.

The port type a number · whiteboard ▶ play

Ana and Ben port a 10-module codebase to the new framework. They split it in half: Ana starts from the top, Ben from the bottom. Ana ports 1 module an hour, Ben ports 2. When both halves are done, what percent of the modules did Ana port?

Answer: 50

Hint: Read the second sentence again. Who decided how much each person does?

Explain: 50. They split it in half before starting, so speed never mattered. Ben just finished first and went for coffee.

The sinking cluster type a number · chain ▶ play

The old cluster dies in exactly 20 minutes. 15 services are still on it. The migration job moves 5 at a time, but one slot must always carry the coordinator, who rides back for the next batch. A one-way trip takes 4 minutes. How many services can you save?

Answer: 13

Hint: Count trips: over, back, over, back, over. The last trip does not need to come back.

Explain: 13. Trips leave at minute 0, 8 and 16, each carrying 4 services plus the coordinator. The last trip at minute 16 can fill all 5 slots. 4 + 4 + 5 = 13.

Left running type a number · code ▶ play

Ten laptops sit on the office table on battery, all running the test suite. Before you leave you close two of them. Later, someone closes one more. The rest run all night. In the morning, how many laptops still have battery?

Answer: 3

Hint: Think about what a laptop running on battery all night looks like by morning.

Explain: 3. The seven that kept running are dead. Only the three that were closed still have charge. Sometimes the answer is the boring one.

The doubling log type a number · code ▶ play

A bug makes one log line copy itself every minute: 1 line, then 2, then 4, and so on. After 60 minutes the disk is full. After how many minutes was the disk half full?

Answer: 59

Hint: Each minute the size doubles. Work backwards from full.
